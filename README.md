# ✦ DRAW IT — QR 연동 디지털 방명록 (웹 버전)

큰 화면(태블릿·TV·PC)에 QR 코드를 띄워 두면, 손님이 휴대폰으로 스캔해 **그림을 그려 보내는 순간**
미디어월 가운데로 그림이 반짝 하고 나타납니다. 그 순간 화면의 **모든 캐릭터가 눈동자와 몸을
새 그림 쪽으로 돌려 쳐다보고**, 몇 초 뒤 자연스럽게 제자리로 돌아옵니다.

이 버전은 **서버가 필요 없는 정적 웹앱**입니다. GitHub Pages 같은 정적 호스팅에 올리면
인터넷 주소 하나로 바로 쓸 수 있고, 손님 휴대폰과 큰 화면이 **같은 와이파이가 아니어도**
실시간으로 연결됩니다.

```
휴대폰 draw.html?room=XXXX ──┐                        ┌──▶ 태블릿 index.html
                             ├─ ntfy.sh (공개 중계) ──┤     스포트라이트 등장 + 시선 반응
        그림 그리기 / 전송     └────────────────────────┘     localStorage 에 영구 저장
```

## 1. 접속 주소

| 화면 | 주소 |
| --- | --- |
| **미디어월(큰 화면)** | <https://iamakmi.github.io/draw-it/> |
| 그리기(휴대폰) | `https://iamakmi.github.io/draw-it/draw.html?room=<방코드>` — 미디어월 QR 로 자동 열립니다 |
| 관리자 | <https://iamakmi.github.io/draw-it/admin.html> |

> 💡 미디어월은 태블릿/PC 브라우저에서 `F11`(전체화면)로 틀어 두면 가장 예쁩니다.
> 주소 끝에 `?room=코드`를 붙이면 그 방으로 바로 열립니다. (예: `.../draw-it/?room=K7M2PQXH`)

## 2. 사용 방법

### ① 큰 화면 (미디어월)

- 상단에 `DRAW IT`, 하단 가운데에 **QR 코드와 방 코드**가 있습니다.
- 샘플 방명록 12개가 파스텔 카드로 둥실둥실 떠 있습니다.
- 손님 그림이 도착하면 → 화면 가운데 **스포트라이트**로 크게 등장 → 반짝임 → 빈 자리로 이동.
  그동안 다른 그림들의 **눈동자와 몸이 모두 새 그림을 바라봅니다.**
- 그림은 브라우저(`localStorage`)에 저장되어 **새로고침해도 그대로** 남습니다. (방마다 최대 48개)

**단축키**

| 키 | 기능 |
| --- | --- |
| `T` | 테마 전환 (라벤더 → 크림 → 나이트) |
| `Q` | QR 패널 표시 / 숨김 |
| `H` | 타이틀·QR·버튼 모두 숨기기 (사진 찍을 때) — `Esc` 로 복귀 |
| `F` | 전체화면 |

**터치 버튼** — 태블릿·스마트폰에는 단축키 대신 왼쪽 아래 작은 버튼을 씁니다.
테마 · QR · **새 방** · 방명록 비우기 · 화면 숨기기, 그리고 `⌄` 로 버튼을 접을 수 있습니다.

### ② 휴대폰 (그리기)

1. QR 을 스캔하면 그리기 화면이 바로 열립니다. (방 코드가 없으면 코드를 입력하는 화면이 뜹니다)
2. **도안** — 둥근 말풍선 / 구름 / 하트 / 별 / 고양이 / 곰 (6종)
3. **배경** 파스텔 8색, **펜** 8색, 굵기 3단계, 지우개, 되돌리기, 전체 지우기
4. **Fill your bubble!** 을 누르면 큰 화면에 즉시 전송됩니다.

> 그리는 동안 도안 위의 눈동자가 손가락을 따라 움직입니다.

### ③ 관리자

- 지금 방 코드와 QR, 방 목록(이전 방 다시 열기)
- **새 방 만들기** — QR 주소가 새로 바뀝니다
- 화면 설정: 테마 · QR 위치 · QR 표시 · 타이틀 · 안내 문구 (저장하면 열려 있는 미디어월에 바로 반영)
- 이 기기에 저장된 방명록 목록 · 개별 삭제 · 전체 비우기 · 샘플 12개 다시 채우기

## 3. 실시간 연결 방식

- **중계 서비스**: [ntfy.sh](https://ntfy.sh) 의 공개 pub/sub 채널 (HTTPS 443 표준 포트, 무료, 가입 불필요)
- 보내기: `POST https://ntfy.sh/drawit-<방코드>` / 받기: `wss://ntfy.sh/drawit-<방코드>/ws`
- WebSocket 이 막히는 망(학교·회사 와이파이 등)에서는 자동으로 **HTTP 폴링**으로 넘어갑니다.
- ntfy 메시지 하나는 4KB 제한이 있어, 그림 좌표를 **36진수로 압축**하고 길면 여러 조각으로 나눠
  보낸 뒤 받는 쪽에서 이어 붙입니다.

### 알아 둘 점

- 방 코드는 8자리 무작위 값이라 남이 추측하기 어렵지만, **공개 중계 채널**을 쓰기 때문에
  방 코드를 아는 사람은 그 방의 그림 신호를 받아볼 수 있습니다. 민감한 내용은 그리지 마세요.
- 한 방에 아주 많은 사람이 동시에 몰리면 ntfy 무료 한도의 rate limit 에 걸릴 수 있습니다.
  (손님 수십 명 규모의 행사에는 충분합니다)
- 인터넷이 끊기면 새 그림은 오지 않지만, 이미 받은 그림은 브라우저에 남아 화면이 비지 않습니다.

## 4. 폴더 구조

```
draw-it/
├── index.html          미디어월 (큰 화면)
├── draw.html           모바일 그리기
├── admin.html          관리자
├── css/
│   ├── base.css        공통 테마 변수
│   ├── display.css     미디어월 (+ 터치 버튼)
│   ├── draw.css        그리기 화면
│   └── admin.css       관리자
├── js/
│   ├── shapes.js       도안 6종 정의 (공용)
│   ├── relay.js        ntfy 중계 · 좌표 압축 · 조각 이어붙이기
│   ├── seed-data.js    샘플 방명록 12개 (미리 생성)
│   ├── display.js      배치 · 시선 반응 · 스포트라이트 · 저장
│   ├── draw.js         캔버스 드로잉 · 전송
│   └── admin.js        관리자
└── vendor/qrcode.js    QR 생성기 (MIT, Kazuhiko Arase)
```

## 5. GitHub Pages 로 올리기

```bash
git clone https://github.com/iamakmi/draw-it.git
cd draw-it
# 파일 수정 후
git add -A && git commit -m "update" && git push
```

`main` 브랜치 루트가 그대로 배포됩니다. (Settings → Pages → Source: Deploy from a branch / main / root)
